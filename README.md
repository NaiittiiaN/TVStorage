# TV Storage (v1.2.3)

Приложение для учёта и контроля хранения телевизоров в сервисном центре. Оптимизировано для работы на Android TV приставках и смартфонах.

## 🚀 Основные возможности

*   **💻 Удаленный доступ**: Управляйте базой данных через браузер на ПК (порт настраивается в приложении, по умолчанию 4848). Доступно добавление, редактирование и удаление записей.
*   **📺 Оптимизация для ТВ**: Прямоугольные ячейки 16:9, фиксированная сетка 5x3 и полная поддержка управления пультом (D-pad).
*   **📱 Адаптивный интерфейс**: Автоматическое переключение в режим 3x7 при вертикальном использовании на телефоне.
*   **⏱ Умный таймер**: Отслеживание времени хранения с точностью до минут.
*   **🎨 Цветовая индикация**: Фон плитки меняется в зависимости от срока хранения:
    *   ⚪ 0-3 дня: Белый
    *   🟢 4-6 дней: Светло-зеленый
    *   🟠 7-9 дней: Светло-оранжевый
    *   🔴 10+ дней: Светло-красный
*   **🔍 Поиск и Сортировка**: Быстрый поиск по S/N (серийному номеру) и сортировка по дате или стоимости.
*   **💾 Резервное копирование**: Возможность сохранения и загрузки базы данных из файла.
*   **🔄 Автообновления**: Проверка и установка новых версий напрямую из этого репозитория.

## 🛠 Технологии

*   **Kotlin & Jetpack Compose**: Современный UI.
*   **Room Database**: Надежное локальное хранение данных.
*   **Ktor (Server & Client)**: Реализация веб-интерфейса и системы обновлений.
*   **Hilt**: Внедрение зависимостей.
*   **GitHub Actions**: Автоматическая сборка релизов.

## 📦 Установка и использование

1.  Скачайте актуальный APK из раздела [Releases](https://github.com/NaiittiiaN/TVStorage/releases).
2.  Для удаленного управления с ПК:
    *   Убедитесь, что устройство и ПК в одной Wi-Fi сети.
    *   Зайдите в «Настройки» приложения.
    *   Введите указанный IP-адрес в браузере (например, `http://192.168.1.15:4848`).

## 🤝 Разработка

Чтобы собрать проект самостоятельно:
1. Клонируйте репозиторий.
2. Откройте в Android Studio (Ladybug или новее).
3. Выполните сборку через Gradle: `./gradlew assembleDebug`.
