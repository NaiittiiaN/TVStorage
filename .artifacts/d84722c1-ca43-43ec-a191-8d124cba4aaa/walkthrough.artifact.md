# Обновление TV Storage v1.2.5

В этой версии исправлено поведение клавиатуры на Android TV и обновлена система версий для автоматического обновления.

## Основные изменения

### ⌨️ Исправление клавиатуры (v1.2.5)
- **TvTextField**: Новый компонент, предотвращающий самопроизвольное открытие клавиатуры.
- **Оптимизация для ТВ**: При навигации пультом клавиатура не мешает обзору, пока вы явно не нажмете "ОК" на поле.
- **Быстрый старт**: При добавлении нового ТВ поле S/N активируется сразу.

### 🚀 Система обновлений
- Версия приложения поднята до **1.2.5** (versionCode 7).
- Обновлен файл `README.md` и список "Что нового".

## Что нужно сделать для завершения обновления на GitHub:

> [!IMPORTANT]
> Я обновил все файлы локально, но я не могу напрямую отправить их в ваш GitHub репозиторий. Чтобы обновление заработало на приставке, вам нужно:
> 1. **Закоммитить и запушить** изменения в ваш репозиторий.
> 2. **Создать новый Release** на GitHub с тегом `v1.2.5`.
> 3. **Прикрепить скомпилированный APK** к этому релизу.
>
> После этого приставка при проверке обновлений увидит версию 1.2.5 и предложит обновиться.
